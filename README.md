# כרם · Food Cost

אפליקציית תמחור מנות ליקב, בעברית וב־RTL. ללא backend וללא חשבון משתמש.

## הרצה ופיתוח

דרישות: Node.js 22 ומעלה, pnpm 11.25.0.

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm preview
```

פתחו את הכתובת שמודפסת עם הנתיב `/FoodCost/`. בדיקות offline מתבצעות בגרסת production (`pnpm build` ואז `pnpm preview`), ולא בשרת הפיתוח.

## תכולה

- חומרי גלם: אריזה, מחיר לפני מס, ניצולת ויחידות תואמות.
- מתכוני משנה מקוננים, מניעת מעגלים, ותפוקה לאחר הכנה.
- מנות ואצוות, יעד Food Cost ובדיקת מחיר מכירה קיים.
- הגדרת בסיס מס, עיגול כלפי מעלה, המרת מחירים קיימים כשמשנים בסיס.
- חיפוש, קטגוריות, שכפול, ארכוב ומחיקה שמוגנת מפני הפניות פעילות.
- IndexedDB באמצעות Dexie; חישובים עשרוניים באמצעות Decimal.js.
- גיבוי JSON, בדיקת תקינות ותצוגה מקדימה לפני החלפה אטומית.
- PWA עם משאבים מקומיים ו־Service Worker שנוצר בזמן הבנייה.

נתוני הדגמה יתווספו רק בלחיצה על ״טעינת דוגמה״. אין מידע אמיתי במאגר.

## פרסום ל־GitHub Pages

במאגר GitHub: Settings → Pages → Source → GitHub Actions.
לאחר מכן הפעילו את התהליך `Test and publish to GitHub Pages`, או דחפו שינוי ל־main.
הכתובת הצפויה: https://shlomis23.github.io/FoodCost/

ההגדרות מניחות שם מאגר FoodCost. בשינוי שם מאגר יש לעדכן `base` ב־vite.config.js. הניווט משתמש ב־hash כדי שקישור ישיר ורענון לא יגרמו לשגיאת 404.

## נתונים וגיבוי

נתוני המכשיר אינם נשלחים לשרת. גיבוי מוריד קובץ מקומי; על המשתמשת לוודא שהקובץ נשמר. אין סנכרון בין מכשירים. ניקוי נתוני האתר עלול למחוק נתונים. אין לשמור קובצי גיבוי אמיתיים במאגר ציבורי.

שחזור מחליף את התוכן הקיים ואינו ממזג אותו. רק פורמט גיבוי בגרסה 1 נתמך כרגע. לפני שינוי schema יש להוסיף migration מפורש ובדיקות שדרוג; אין לאפס מסד קיים אוטומטית.

## משמעות החישוב

הכמויות במתכון הן שימושיות לאחר ניצולת חומר הגלם. תפוקת מתכון משנה היא התפוקה הסופית לאחר ההכנה. לא מתווסף פחת נוסף. העלויות כוללות חומרי גלם בלבד. המחיר המומלץ מבוסס על יעד מוגדר ואינו תחשיב רווח נקי.

מחירי רכש הם לפני מס. שיעור המס הוא ערך שהמשתמשת מזינה, ואינו ייעוץ מס. ברירת המחדל היא מחירי מכירה לפני מס, יעד 30% ועיגול כלפי מעלה לשקל.

## בדיקות ידניות לפני שימוש שוטף

יש לבדוק במכשיר היעד (Safari ב־iPhone או Chrome ב־Android): התקנה ממסך הבית, יצירת ושחזור קובץ JSON, סגירה ופתיחה מחדש, עבודה במצב טיסה ועדכון גרסה. בדיקות שולחן עבודה אינן מחליפות בדיקת מכשיר אמיתי.
